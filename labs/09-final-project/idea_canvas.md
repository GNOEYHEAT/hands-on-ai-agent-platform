# 아이디어 캔버스

팀 이름:
작성자:

| 칸 | 질문 | 우리 답 |
| --- | --- | --- |
| 1. 사용자 | 누가 쓰는가? 어떤 상황에서? | |
| 2. 문제 | 지금 무엇이 불편한가? 얼마나 자주? | |
| 3. 에이전트 역할 (Instruction) | 에이전트는 무엇을 하고, 어떤 형식으로 답하는가? 하지 말아야 할 것은? | |
| 4. 도구 (Tool) | 에이전트가 호출할 기능 1~3개. 함수 이름, 입력, 출력 | |
| 5. 화면 (AG-UI) | 채팅 외에 보여 줄 것(도구 상태 카드, 결과 패널 등) | |
| 6. 위험 | 키·개인정보·잘못된 답·권한 문제와 대응(SEC 항목 번호) | |

## 도구 설계 메모

```python
def 도구_이름(입력: str) -> dict:
    """언제 쓰는 도구인지 한 줄로."""
    return {"status": "success", ...}
```

## 3분 발표 순서

1. 사용자와 문제(30초)
2. 에이전트 역할·도구·화면(60초)
3. 시연(60초)
4. 위험과 다음 단계(30초)
