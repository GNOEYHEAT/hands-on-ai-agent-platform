# advanced 커리큘럼과 시간 배분표

초급~중급, 1일 300분(09:00~12:00, 13:00~15:00. 모듈 275분 + 휴식·질의응답 25분, 점심 별도). 개념 설명 약 38% / 실습 약 62%. 실습 절차는 [README의 advanced](../../README.md#advanced)를 따른다.

설치는 강의 시간에 넣지 않았다. `pip install`과 `npm install`은 강의 전에 끝내는 것을 권장한다. 키 발급은 가능하면 강의 전에 끝내고, 못 했다면 실습 L4에서 키 발급 화면을 따라 하거나 `--mock`으로 진행한다([사전 준비 가이드](../prep-guide.md)).

## 강의 뒤 이어 하기

내용을 줄이지 않았으므로, 300분 안에서 다 못 한 부분은 강의 뒤로 넘긴다.

- 각 PART의 '⑤ 실습 확장'(`.goosehints`, 공개 MCP 서버, 공유 상태·HITL 등)은 강의에서 소개만 하고 강의 뒤 과제로 남긴다.
- PART 5 확장판(90분): 설계 10 → 개발 40 → UI 연결·테스트 20 → 발표 20(팀당 3분). [최종 프로젝트 가이드](final-project-guide.md)에 있다.

2일 과정으로 늘리면 PART 5를 2일차 전체(해커톤 개발 시간)로 확장한다.
