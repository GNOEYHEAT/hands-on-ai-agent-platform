# advanced 커리큘럼과 시간 배분표

초급~중급, 1일 480분(모듈 420분 + 휴식·질의응답 여유 60분, 점심 별도). 개념 설명 30% / 실습 70%. 실습 절차는 [README의 advanced](../../README.md#advanced)를 따른다.

## 시간 배분표

| 모듈 | 분 | 실습 | 실습(분) |
| --- | --- | --- | --- |
| PART 1. LLM API 및 AI 에이전트 개발 환경 구축 | 70 | L4, L5 | 45 |
| PART 2. Google ADK 기반 AI 에이전트 개발 | 110 | L6, L7, L8 | 75 |
| PART 3. AG-UI 기반 사용자 인터페이스 개발 | 100 | L9, L10 | 65 |
| PART 4. AI 에이전트 보안 및 거버넌스 | 50 | L11 | 30 |
| PART 5. 나만의 AI 에이전트 프로토타입 | 90 | L12 | 60 |
| 합계 | 420 | | 275 |

| 시각 | 내용 |
| --- | --- |

2일 과정으로 늘리면 PART 5를 2일차 전체(해커톤 개발 시간)로 확장한다.
